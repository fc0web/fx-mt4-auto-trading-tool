## ⚠ 最初にお読みください — 投資リスクに関する重要事項

本リポジトリで配布されているのは **MT4 用 EA のソースコード** です。 以下の事項を理解した上で、 ご自身の責任でご利用下さい。

### 本ツールが「**しない**」こと

- **投資助言は一切行いません。** 「この通貨ペアを買うべき」「この時間帯が勝てる」 等の助言情報は含まれません。
- **取引代行サービスではありません。** EA は **あなたのご自身の MT4 上で、 あなたのご自身のブローカー口座に対して** 動作します。 本リポジトリの公開者はあなたの取引に一切関与しません。
- **性能は保証しません。** 過去の成績・勝率・期待値などの数値は一切提示していません。 提示されたとしても将来の成果を保証するものではありません。
- **IB (Introducing Broker) / アフィリエイトリンク・特定ブローカー誘導は一切ありません。**

### 本ツールに関する **本質的なリスク**

★★★ 以下は EA の設計を honest に説明したものです。 隠さず明記します ★★★

1. **FX 取引そのものが元本超過損失のリスクを伴います。** 個人投資家の多くが損失を出すと統計的に示されています。
2. **本 EA はナンピン (Nanpin = averaging down) と マーチンゲール倍率 (Martingale) の機能を含みます。** 初期設定では:
   - ナンピン機能: **ON**
   - マーチン倍率: **2.0 倍** (含み損で段が増える毎にロット倍々)
   - 最大ナンピン段数: **100 段**
3. **マーチンゲール戦略の数学的特性**:
   - 2 倍マーチンを 10 段重ねると、 基準ロットの **2^10 = 1,024 倍** のポジション
   - 17 段で **約 13 万倍**、 20 段で **約 100 万倍**
   - 「どこかで反転する」 という期待に対し、 反転しなかった場合に **証拠金を全消失する** 結果になります
   - これは EA の品質の問題ではなく、 **マーチンゲール戦略の数学的宿命** です
4. **デフォルト設定で実口座運用すると、 マーケットの強いトレンドに飲まれた際に口座を失うリスクがあります。** 必ずデモ口座で挙動を確認し、 各パラメータを理解した上でご利用下さい。
5. **グリッド機能を両建てモード (gridBoth) で使うと、 露出が倍以上になります。** これも同様のリスクを伴います。

### お願い (強く推奨)

1. **必ずデモ口座 (Demo Account) から開始して下さい。** 全パラメータの動作を理解するまで実口座は使わないで下さい。
2. **少額・最小ロットから開始して下さい。** 0.01 ロット (マイクロロット) が初期値推奨です。
3. **ストラテジーテスター (Strategy Tester) でバックテストして下さい。** ただしバックテスト結果は将来の成果を保証しません。
4. **理解できないパラメータは OFF にして下さい。** v4 で追加された機能 (A)〜(H) は全てデフォルト OFF です。

## このリポジトリの構成

| ファイル | 説明 |
|---|---|
| `Object_EA_Grid_v4.mq4` | チャート上のオブジェクト (矢印コード / 色) を読み取ってエントリーシグナルを検出する EA |
| `Buffer_EA_Grid_v4.mq4` | iCustom 経由でインジケータのバッファ値を直接読み取って判定する EA |
| `README.md` | 本ファイル |
| `LICENSE` | MIT ライセンス |
| `.gitignore` | コンパイル後の .ex4 等を除外 |

★ **Object 版と Buffer 版はサイン認識方式が違うだけで、 ナンピン / マーチン / グリッド / MM / トレーリング 等の中核ロジックは共通**です。 ご自身のインジケータの実装方式に合わせて選んで下さい:

- 矢印やドット等を **チャート上のオブジェクトとして描画する** インジ → **Object 版**
- バッファに数値を書き込む通常のインジ (移動平均、 RSI、 ストキャス 等) → **Buffer 版**

## インストール

1. `Object_EA_Grid_v4.mq4` または `Buffer_EA_Grid_v4.mq4` をダウンロード
2. MT4 のデータフォルダを開く: `ファイル` → `データフォルダを開く`
3. `MQL4/Experts/` フォルダにコピー
4. MetaEditor を起動 → コンパイル (F7) → エラーなく `.ex4` が生成されることを確認
5. MT4 のナビゲータで「エキスパートアドバイザ」 → 当該 EA をチャートにドラッグ
6. パラメータダイアログで **必ず設定を確認** してから「OK」 (デフォルトのままで実口座運用は推奨しません)

★ MT4 の `自動売買` ボタンが ON になっていることを確認。 各 EA のスマイリーマークが「:)」になっていれば稼働中です。

★ **必ずデモ口座でテストしてから本番運用して下さい。**

## よくある質問 (FAQ)

### Q1. Object 版と Buffer 版、 どちらを使えばいい?

A. ご自身の使うインジの「サインの出方」によります:
- **矢印やドットをチャートに描く**インジ (ZigZag 系、 矢印系) → **Object 版**
- **バッファに数値を入れる**通常インジ (MA、 RSI、 MACD、 ストキャス 等) → **Buffer 版**

### Q2. 初期設定のままで使っていい?

A. **推奨しません。** デフォルトはナンピン ON + マーチン 2.0x + 100 段の設定で、 強いトレンドに飲まれた場合に大損失リスクがあります。 必ず以下を検討してから運用して下さい:
- ナンピン段数を下げる (例: `maxNan_Buy/Sel = 5` 等)
- マーチン倍率を下げる (例: `nanMartinBuy/Sel = 1.0` で同ロット、 リスク低)
- 最初は最小ロット (0.01) で
- 必ずデモ口座で挙動確認

### Q3. 推奨通貨ペア / 時間足は?

A. **本リポジトリでは推奨しません。** 「この通貨ペア・時間足で勝てる」 と提示することは投資助言に近づくため、 honest に何も推奨しません。 ご自身の検証で決めて下さい。

### Q4. 過去のバックテスト結果や勝率を見せてほしい

A. **本リポジトリでは公開しません。** バックテスト結果は将来の成果を保証しないことに加え、 過去成績の提示は投資助言業の規制対象に近づくため、 honest に何も提示しません。 ご自身で MT4 ストラテジーテスターを使って検証して下さい。

A. **補償しません。** 本ツールは MIT ライセンスで「AS IS」 (現状のまま) で配布されており、 商品性や特定目的への適合性を一切保証しません。 LICENSE をお読み下さい。
